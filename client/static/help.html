TonightSky Help

Introduction

Welcome to TonightSky, your companion for planning astronomical observations. This guide will help you navigate the app's features and use it effectively.

Settings

Customize your observation parameters using the settings panel:

  • Latitude & Longitude: Enter your observation location's coordinates.
  • Timezone: Search and select your local timezone to ensure accurate calculations.
  • Filters: Use the catalog filters and query expressions to narrow down your object list.

Equipment Profiles

Equipment profiles let you capture your imaging setup so Tonight's Best can estimate frame fit and suitability. You can create, edit, import, export, and select profiles from the profile management controls.

  • Profiles are stored in this browser only, so use Export/Import to move them between devices.
  • Each profile stores focal length, aperture, and sensor dimensions used to derive the field of view.
  • Select a profile before running Tonight's Best so the ranking uses your actual imaging setup.

Horizon Profiles

Horizon profiles let you model your local skyline for the altitude graph and for Tonight's Best. You can import one or more Stellarium-style .hrz files and keep them locally in the browser.

  • Select a custom horizon profile to overlay your local skyline on the graph.
  • If no horizon profile is selected, the app falls back to the server's default horizon configuration or a flat 25° horizon.
  • Use the empty selection option to skip the custom horizon and keep the flat default.

Filter Query

The Filter Query field allows you to perform SQL-like queries directly on the table data. Use the header names in lowercase, including spaces, to build your query.

Logical Operators:

  • and = and, *, &
  • or = or, |, +

Example Queries:

  • altitude > 50 and relative tt < 03 and direction = south
  • magnitude < 5 and type = galaxy
  • transit time > '21:00' and altitude > 30
  • catalog = messier and magnitude < 6
  • before/after = before and altitude < 20
  • (type = Globular Cluster or type = Planetary Nebula) and magnitude < 8

Table and Graph Tips

  • Click a column header to sort the table ascending or descending.
  • Click an Altitude cell to open the Altitude Graph for that target.
  • The Altitude Graph highlights the visible period in green and shows the selected horizon overlay when available.
  • Use the Altitude Graph to see when an object rises, transits, and sets, and to check whether your local skyline blocks it at certain times.
  • Times between 00:00 and 11:59 are treated as the morning of the next day.
  • Double-click a row to open the object on an external astronomy reference site.

Tonight's Best

Tonight's Best reorders the already-filtered object list for imaging suitability rather than simply returning catalog order.

  • It requires a selected equipment profile so the field of view can be calculated.
  • It optionally uses a selected horizon profile to evaluate whether the object is above your local skyline during the night.
  • The results add Score and Shooting Time columns.

The score is built from size fit, brightness, best shooting window, and moon distance. The formula is composite = size_score × (0.5 × brightness_score + (1/3) × time_score + (1/6) × moon_score).

In practice, size fit acts as the main gate: if an object is too large for your selected field of view, its score drops to zero. Brightness is based on magnitude, the shooting-window score comes from the longest clear run during astronomical darkness, and the moon score falls when the Moon is bright and close to the target.
